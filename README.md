## 概覽

此專案是 **高中自主學習 [SmartAssistant](https://github.com/irukatun/SmartAssistant)** 的延伸，將原先 Vibe Coding 代碼進行重構並且延續實作的專案，一年多來的技術積累使我們對專案有了更深入的理解，決定在未來繼續完善所有的功能。

**小鹿米智慧桌上助理**是一台設計用於桌面陪伴的裝置，常駐於桌面上，待機時是一個可愛的小時鐘，可以顯示即時天氣和氣溫等資訊，使用者可以透過觸控、語音、敲擊或是晃動之類的動作和鹿米互動，而鹿米也會時刻注意用戶的一舉一動，主動的提醒喝水、久坐站立、用眼休息等等，同時提供統計數據給用戶做為優化生活品質的參考。

## 特色功能
- 多功能小時鐘: 顯示時間、天氣、通知等等
- 語音對話: 用語音與小鹿米聊聊天 (由 Irukatun Lucilla AI 提供)
- 智能行為辨識: 辨識閱讀、使用電腦、使用手機、喝水等，並根據偵測結果和時長觸發主動提醒並記錄行為統計數據。
